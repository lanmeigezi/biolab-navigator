# 生信与虚拟实验资源导航 · BioLab Navigator

生物信息学与虚拟实验的一站式资源导航：从文献检索、序列与结构、通路网络、组学数据、比对进化、数据分析与绘图，到虚拟实验与虚拟细胞世界模型。

- **17 个分类 · 152 个资源 · 149 条直达链接**
- 单文件页面（`index.html`），无依赖、可离线打开、可收藏
- 默认只展示每个分类里最常用的若干项，其余折叠，点「展开其余 N 项」查看全部；一行放得下的分类直接全展示
- 支持拼音 / 缩写搜索（例如 `wxjs`、`jczj`、`blast`、`zhiwang`），可导出书签

## 使用

直接打开 `index.html`，或访问 GitHub Pages：

https://lanmeigezi.github.io/biolab-navigator/

## 说明

- 标「中大已订」的资源，中山大学已购买，请从图书馆入口进入（校外先走 CARSI 认证）
- 标「国外」的部分站点可能需要科学上网；标「需注册」「部分免费」的按各站实际政策
- 资源链接的可用性会随时间变化，遇到失效欢迎提 issue
